# (1) Địa Ốc Hub - A Property Management System

Địa Ốc Hub is a centralized web-based property management system designed to help property owners and small property management teams efficiently manage rental properties, tenants, and financial workflows.

Traditional property management often relies on fragmented tools such as spreadsheets, paper contracts, and manual tracking systems. This can lead to issues such as missed payments, poor expense tracking, and difficulty monitoring property performance.

Địa Ốc Hub addresses these problems by providing an integrated platform where owners, managers, and tenants can interact through structured workflows. The system supports property management, tenant leasing, billing, expense tracking, and payment verification while maintaining role-based access control for different users.

The platform aims to reduce administrative overhead, improve financial transparency, and streamline communication between property owners, managers, and tenants through a centralized digital solution.

# (3) Completed Features

## 1. Login & Register

* Create a new user account
* Log in to an existing account
* Handle invalid login credentials
* View user profile information
* Log out from the system

⸻

## 2. Property Management (Owner)

Owners have full control over their properties and financial operations.

Features include:

* Create, edit, and delete properties
* Create, edit, and delete units within a property
* Generate invitation codes for managers and tenants
* Manage billing and invoices
* Record and manage property expenses
* Review and verify tenant payment submissions
* Manage lease agreements
* Receive and manage system notifications

⸻

## 3. Manager Workflow

Managers can assist property owners in managing operational tasks but have restricted permissions.

Features include:

* Enter invitation codes to request access to a property
* View property information
* Manage expenses
* Review tenant payments
* Manage lease records
* Receive system notifications

Note: Managers cannot modify sensitive financial settings such as the owner’s receiving account.

⸻

## 4. Tenant Workflow

Tenants can access property information and interact with their rental unit through the platform.

Features include:

* Enter invitation codes to request connection to a rental unit
* View property and unit information
* View rent fees and lease details
